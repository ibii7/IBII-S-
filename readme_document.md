## Case Study 1: Internship AI/ML Execution Task

### Beat 1: The Problem

I got a GitHub repo full of unsolved code — some bugs to fix, some functions missing entirely. Part of an internship task built around AI/ML fluency: use AI chatbots to actually get the work done.

### Beat 2: What I Did (and Decided)

I pasted whole files into the chatbot instead of just the broken snippet. Reason: an isolated function out of context creates confusion — the AI needs to see how a piece fits into the rest of the file to fix it right.

I didn't test every fix rigorously before pushing. One slipped through with a missing file extension. I caught it, attached the correct extension, and fixed it before final submission.

### Beat 3: What Came of It

All tasks completed and submitted. Repo went in clean, no outstanding bugs left behind.
